# По вкусу

Локальный демонстрационный магазин без сторонних API, пакетов и ключей.

Запуск: `node server.cjs`, затем http://127.0.0.1:4187.
Админка: http://127.0.0.1:4187/#admin.

48 позиций, поиск, фильтры, карточки, фасовки, помол, избранное, корзина, тестовые заказы, остатки, администрирование каталога, черновики инструкций, публикация и откат версий, база знаний, тестовый чат и история диалогов. Все данные в localStorage одного браузера. Это не защищённая админка и не работающий коммерческий магазин.

Консультант работает по правилам без языковой модели. Имя, выбранный тон, приветствие, вопросы, категории, число рекомендаций и ответы FAQ применяются сразу. Свободный промпт сохраняется для будущей интеграции языковой модели и сейчас не исполняется.

Основные изображения товаров — отдельные постановочные ИИ-иллюстрации сервировки в едином тёплом стиле: керамика, напиток, мягкий дневной свет. Они помечены в каталоге и карточке. Созданы встроенным imagegen, для показа на сайте API не требуется. Оптимизированные файлы — dist/assets/studio, исходники — source-images/serving-v1, промпты — studio-prompts.json.

Вторыми изображениями в карточках сохранены 42 реальные фотографии сортов/сырья/ингредиентов из Wikimedia Commons и 6 композиций из фотографий компонентов наборов. Источники и лицензии — dist/credits.html и photo-manifest.json. Можно переключаться между сервировкой и видом сырья. Фото и иллюстрации не подтверждают внешний вид конкретных поставок или упаковки. Главная также использует атмосферные фото Unsplash. Описания, составы и происхождение демонстрационные. Цены и остатки тестовые. Шрифты Google Fonts имеют системные запасные варианты.

Проект ограничен демонстрацией для портфолио. Реальные продажи, платежи, доставка и серверная интеграция не входят в текущий объём.
Готовый стартовый промпт находится в app.js (`initialPrompt`) и в интерфейсе админки. Секреты в админку не вводить.

## Консультант и админка
В админке доступны образцы характера, структурированные настройки, база FAQ, отдельная тестовая площадка, шесть автоматических сценариев, сохранение черновика, публикация, история и возврат версии, экспорт настроек JSON. Консультант помнит бюджет и вкусы, выбирает до 2–3 товаров в наличии, сравнивает варианты и показывает приготовление. Тестовые диалоги исключены из истории сайта. Данные остаются в браузере. Проверки: node check.cjs и node agent-check.cjs.
