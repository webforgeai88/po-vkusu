# Сервер консультанта «Лея»

Небольшой сервер без зависимостей (Node 24) между чатом на сайте и Yandex AI Studio (модель Alice AI LLM Flash).

- Ключ Яндекса хранится только на сервере (`YC_API_KEY`, `YC_FOLDER_ID` в файле окружения), в репозиторий не попадает.
- Каталог читается из `catalog.json` (выгружается скриптом `export-catalog.mjs` из `dist/app.js`), а не приходит из браузера.
- Модели показываются только товары, подходящие под бюджет, «без кофеина» и «без кислинки»; ответ дополнительно проверяется (цены, названия, ограничения).
- Лимиты: 12 сообщений за 10 минут и 30 в сутки с одного адреса, 100 в сутки на весь сервер, ответ модели не дольше 20 секунд.
- Если сервер недоступен, лимит исчерпан или ответ не прошёл проверку, чат на сайте отвечает по сценарному режиму (файл `dist/agent-demo.js`).
- Выключить ИИ без остановки сервера: создать файл `disabled` рядом с `server.mjs`.
- Проверка на каверзных вопросах: `node probe.mjs`.
